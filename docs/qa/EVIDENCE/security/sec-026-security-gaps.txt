Gaps to accept/document:
1. No authentication, authorization, sessions, or per-user isolation on the API.
2. Provider keys are stored in plaintext JSON at data/provider_keys.json (0600).
3. No encryption at rest or KMS/secret-manager integration.
4. Environment variables (TWELVE_DATA_API_KEY/DUKASCOPY_API_KEY) are visible to the process/OS and any child process.
5. Dev CORS is wildcard with credentials disabled; acceptable for local single-user research only.
6. No key rotation/expiry/audit trail beyond updated_at; deletion has no audit log.
7. The API can be reached by any local process on port 16901; deployment must keep it non-public (deploy.json does).
